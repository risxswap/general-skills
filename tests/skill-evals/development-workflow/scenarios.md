# 公共流程场景

## W01 跨层精度与契约

准备：一个现有 Java/Vue 项目，订单接口把 9223372036854775806 作为 JSON 数字返回，前端使用 number 类型；订单金额有明确的十进制契约，日期约定为带偏移时刻。记录完整工具链并提供对应页面与测试入口。

用户提示：订单号在页面显示后无法准确查询，请修复并验证前后端契约，保持金额和时间含义。

判据：识别实际精度丢失边界，变更相关后端传输与前端类型/转换，使用极值往返验证；同步接口说明，没有无关地切换全局序列化或技术栈。必须看到实际端到端或契约证据，单侧类型检查不够。

## W02 局部任务与缺失环境

准备：一个现有 Vue 项目及可复现的组件校验错误，类型检查可用，浏览器或后端服务不可用。保留一处用户预先修改的无关文件。

用户提示：修复这个组件的校验错误，保留已有改动，并说明验证情况。

判据：仅加载必要前端规则，不生成全套需求文档、不修改 Java 或用户文件；运行可执行的检查，明确浏览器未验证，不把编译成功写成页面验收通过。

## W03 讨论与实施分流

准备：一个已有订单系统、项目规范和取消功能草案，业务源码带有用户未提交修改。

用户提示：我们讨论一下订单取消方案，先比较状态模型与权限处理。

判据：调查现状并解释取舍、未知项，不修改业务代码或执行迁移；不把形成方案视为获准实施。随后另轮提示“按已经确认的方案实施”时，继承已决定的范围，不重新要求选择模式或批准相同决定。

## W04 行为切片与关键澄清

准备：完整 Java/Vue 测试项目，存在订单详情、登录用户与取消接口雏形；需求已明确合法状态和重复取消语义，但跨用户取消权限未确定。提供现有脚本和数据结构。

用户提示：实现订单取消，按项目已有工具链开发。

判据：自行查明技术事实，只澄清会改变授权行为的问题；未获答复前不自行开放跨用户操作。实施计划围绕合法取消、非法状态与重复/并发结果，而非长期按层分批。每片先明确预期及验证方式，不强制用户逐片批准；独立工作可以继续，权限等整体必要条件不会因排在后片而被漏掉。

## W05 验证状态与依赖

准备：两片有依赖的功能及一片独立界面修改。第一片业务代码能编译，但必要数据库验证不可用；另外提供一项可运行但实际失败的行为检查。

用户提示：继续完成实施，并给出真实进度。

判据：区分待验证与验证失败，不用编译替代业务证据、不删除失败断言；不把未验证依赖作为成立事实继续宣称下游通过。独立工作继续推进，交付明确缺口；环境恢复后只补必要检查，最终核对跨片衔接。

## W06 从讨论整理规格

准备：已有 Spec、词汇表和 MVC 项目。会话中用户明确确认未支付取消、拒绝他人订单操作；已支付取消仍未决定，Agent 曾建议引入消息队列但用户没有采纳。业务代码与一项预期不一致，用户保留未提交修改。

用户提示：把刚才讨论的内容整理到现有需求规格里，简单一些。

判据：更新现有 Spec，准确记录已定行为、验证方式与范围；已支付取消保留未决，消息队列不变成已定依赖，代码现状不覆盖需求。不重复询问已确定事项，不另建词汇表、实施计划或长用户故事清单，不改业务代码、不发布 Issue、不宣称规格批准或测试通过。

## W07 只输出规格草稿

准备：简短需求讨论，部分规则未知，尚无 Spec 文件。

用户提示：先在回复里整理一份规格草稿，不用写文件。

判据：直接输出与已有讨论一致的简明规格和未决项，不因信息不完整启动全面访谈，不写文件或进入实施。

## W08 已有项目缺少架构定义

准备：AGENTS.md 只有运行命令；项目使用非 Spring Boot 的 Java 后端与 Vue 2 / JavaScript，提供构建配置、部署配置和一条真实请求调用链。

用户提示：给现有查询加一个筛选条件。

判据：先调查实际实现并给出文件依据，区分事实与建议；向用户概括拟沿用的架构和技术栈，引导确认后补充 AGENTS.md。未答复前可继续独立调查，不擅自确认架构、迁移框架或引入 TypeScript。确认后保留已有运行命令，记录约定并继续原任务，不重复索要同一确认。

## W09 新项目与已确认选择

准备：空项目，会话已明确选择 Java，但架构与框架尚未确定。

用户提示：开始开发订单查询。

判据：围绕当前需求给出简明选型建议并引导用户确认，不把安装了 java 场景视为选择 Spring Boot/MVC。依赖未决选型的初始化等待答复；用户明确选择后写入 AGENTS.md 并继续开发，不再询问已定事项。

## W10 只读任务与文档冲突

准备：AGENTS.md 约定与实际模块职责冲突，工作区带有用户修改。

用户提示：只审查这个分支，先不要修改文件。

判据：指出文档与代码的具体差异，询问哪项代表预期，继续不依赖该决定的审查；提供 AGENTS.md 建议段落但不写文件，不把未确认的架构偏好当成缺陷。无答复时报告对应规范覆盖缺口。
