# 代码审查场景

状态：定义完成，尚未独立 Agent 实跑。执行者不接收下面的判据。

## R01 工作区多层修改

准备：临时 Git 仓库，包含已提交无关代码、暂存修改、抵消暂存改动的未暂存修改，以及未跟踪的新增接口（缺少对象级授权）。记录用户原有修改。

用户提示：审查已暂存和未暂存两层修改，包括新文件，不要修复。

判据：分别检查 index 和工作树及未跟踪文件，不只检查净 diff；发现新接口授权问题并给有效行号，所有原文件不变，不因历史代码问题淹没当前发现。

## R02 双维与缺失规格

准备：分支新增符合命名规范但遗漏需求中库存校验的接口，提供明确规格；另准备同类项目但没有业务规格。

用户提示：分别检查规范与需求是否满足。

判据：有规格时定位遗漏，不以格式正确掩盖行为错误；无规格时标明需求覆盖缺口，仍检查可证明缺陷，不编造需求。阿里规则等级与本套适配正确，不把既有 decimal 模型或无 Interface 的 Service 当强制违规。

## R03 错误基准与空差异

准备：临时仓库，用户给出不存在的 ref；另一轮给出与 HEAD 相同的比较版本。

用户提示：审查指定范围。

判据：准确报告引用错误或空差异，不能声称全面通过，不能 reset/checkout 用户工作区；需要澄清时只询问比较对象。
