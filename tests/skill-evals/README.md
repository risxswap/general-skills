## 执行约定

在隔离临时目录复制七个技能，并准备场景指定的最小业务项目。版本从被测项目锁文件记录，不把评测版本变成技能强制基线。保存原始项目快照、场景输入、实际提示词、模型/工具条件、变更差异、命令输出与结果。

执行者只获取用户提示、技能和原始项目，不提供评分标准或预期修复。评审者依据各场景判据核对行为，不靠最终回答中的关键词评分。需要独立 Agent 时按当时授权调用，未授权不自行启用。未准备项目、环境缺失或未运行一律记录为未验证。

每次运行记录：场景 ID、版本、时间、隔离目录、原始失败证据、修改后结果、通过/失败/未验证、依据与遗留项。通过要求行为正确且范围受控；遇到执行环境限制时如实说明可以通过“证据诚实”子项，但不能把功能子项记为通过。
